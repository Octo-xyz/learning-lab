# LAB-001 — Cómo aprender tecnología

## Pregunta

¿Cómo diseñar un sistema personal para aprender y aplicar tecnologías
a través de proyectos prácticos y escalables?
que se aplique a cualquier área o formato específico de implementación

## Objetivo

Aprender a diseñar una estructura metodológica, lo suficientemente ágil para que permita ser adaptable como inicio ante cualquier proyecto a ejecutar, implementar, diseñar o mejorar.
Desde una base funcional y que con las modificaciones e integraciones y conocimientos adquiridos se pueda moldear a los requerimientos. Esto no es una tech o un recurso copiar y pegar, entiendase como una estructura lógica y metódica

## Hipótesis

Integrar un sistema basado en estructuras de identificación de una base general, diagnóstico, análisis automatizados o no, permite definir un flujo eficiente de trabajo junto con los recursos necesarios para integrar en el sistema con grandes resultados y una estructura hecha a medida para cada necesidad o tecnología que queremos aplicar.

## Experimentos

- integrar primeras herramientas
- identificar componentes del sistema base
- estructurar e identificar los procesos lógicos y metódicos del protocolo
